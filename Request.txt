PCB元器件库与BOM管理助手
一、系统概述
本系统是一个基于大模型（AI Agent）驱动的PCB工程物料管理平台。用户通过自然语言描述需求，大模型自动将其转换为SQL语句并执行，实现元器件库管理、BOM导入解析、封装文件管理、工程统计等功能。系统以表格形式展示操作结果，支持增删改查全流程。


PCB元器件库与BOM管理助手
一、系统概述
本系统是一个基于大模型（AI Agent）驱动的PCB工程物料管理平台。用户通过自然语言描述需求，大模型自动将其转换为SQL语句并执行，实现元器件库管理、BOM导入解析、封装文件管理、工程统计等功能。系统以表格形式展示操作结果，支持增删改查全流程。
1. 物料分类表（component_category）
字段名	说明
category_id	分类ID，主键，自增
parent_id	父分类ID，支持树形结构，为空表示顶级分类
category_name	分类名称，如"电阻"、"贴片电阻"
category_code	分类编码，如RES、CAP、IC、CONN
sort_order	排序序号

2. 元器件库表（component_library）
字段名	说明
component_id	元器件ID，主键，自增
internal_pn	内部料号，唯一，如RES-0805-10K-5%
category_id	分类ID，外键关联component_category
description	物料描述，如"贴片电阻 10KΩ ±5% 1/8W"
footprint_name	PCB封装名称，如0805_L、SOIC-8、SOT-23-5
symbol_name	原理图符号名称
spec_json	规格参数，JSON格式，如{"resistance":"10KΩ","tolerance":"±5%","power":"1/8W","voltage":"50V"}
manufacturer	制造商名称，如Yageo、TI、Murata
manufacturer_pn	制造商料号（MPN）
supplier	供应商名称，如立创商城、云汉芯城、Digikey
supplier_pn	供应商料号（SPN）
unit_price	单价，单位元
currency	币种，默认CNY
price_date	价格更新日期
stock_qty	当前库存数量
datasheet_url	数据手册链接
source_project_id	首次来源工程ID
remark	备注
created_by	创建人ID
created_at	创建时间
updated_at	更新时间

3.封装库索引表（footprint_library）
字段名	说明
footprint_id	封装ID，主键，自增
footprint_name	封装名称，唯一，如0805_L、SOIC-8、BGA-256
category	封装分类：SMD、Through-Hole、BGA、QFN、QFP、SOP、Other
has_3d_model	是否有3D模型，0或1
verified_by	审核人ID
remark	备注
created_by	创建人ID
created_at	创建时间
updated_at	更新时间
4. 封装文件表（footprint_file）
字段名	说明
file_id	文件ID，主键，自增
footprint_id	所属封装ID，外键关联footprint_library
file_type	文件类型：psm、dra、pad、bsm、osm、fsm、ssm、step、pdf、other
file_name	原始文件名
file_path	文件服务器存储路径或对象存储Key
file_hash	SHA256哈希值，用于完整性校验
eda_tool	EDA工具：Allegro、Altium、KiCad、PADS
eda_version	EDA工具版本，如17.4
uploaded_by	上传人ID
upload_time	上传时间
download_count	下载次数
remark	备注

5.PCB工程表（pcb_project）
字段名	说明
project_id	工程ID，主键，自增
project_code	工程编号，唯一，如PRJ-2026-001
project_name	工程名称，如"主板控制板"
version	当前版本号，如V1.0、V2.1
designer	设计师姓名
project_status	工程状态：Active（进行中）、Completed（已完成）、Archived（已归档）、Cancelled（已取消）
description	工程描述
start_date	开始日期
target_date	目标完成日期
created_by	创建人ID
created_at	创建时间
updated_at	更新时间
6. 系统用户表（sys_user）
字段名	说明
user_id	用户ID，主键，自增
username	用户名，唯一
password_hash	密码哈希值
display_name	显示姓名
email	电子邮箱
role	角色：Admin（管理员）、Engineer（工程师）、Viewer（只读用户）
is_active	是否启用，0或1
created_at	创建时间






核心业务功能说明
业务场景1：物料选型查询
用户在PCB设计选型时，需要查询元器件库中是否有满足条件的物料，并获取其封装、价格、库存等信息。
自然语言需求示例：
"帮我查一下0805封装、10KΩ、±5%精度的贴片电阻有哪些？"
"库里有没有SOT-23-5封装、3.3V输出的LDO？"
"查一下TI公司生产的、已经被批准使用的所有IC物料"
"有哪些物料库存低于安全库存了？"
"显示所有停产（Obsolete）的物料"
"查一下内部料号为RES-0805-10K-5%的物料被哪些工程使用过"
预期系统行为：
1.大模型解析用户意图，识别查询条件和目标字段
2.涉及JSON字段（spec_json）时，自动使用对应的JSON查询语法
3.涉及多表关联时，自动编写JOIN语句
4.执行SQL并以表格形式返回结果
5.如果查询结果为空，给出"未找到符合条件的物料"并建议放宽条件

业务场景2：物料管理（增删改）
用户需要对元器件库进行日常维护，包括新增物料、更新物料信息、修改价格、更新库存、设置物料状态等。
自然语言需求示例：
"新增一个物料：内部料号CAP-0603-100nF-10%，分类是电容，封装0603_C，描述是'贴片电容 100nF ±10% 16V'，制造商Murata，制造商料号GRM188R71C104KA01"
"把内部料号RES-0805-10K-5%的单价更新为0.015元，价格日期是今天"
"将物料ID为123的库存数量设置为1000"
"把立创商城供应的所有物料价格上调5%"
"将制造商Yageo、封装0805、且状态为Active的电阻类物料标记为NRND（不推荐新设计）"
"批量导入物料：这里有10个新物料的Excel文件，请解析并导入到元器件库"
"删除内部料号TEMP-001，这是测试数据"
预期系统行为：
1.新增物料时，自动检查内部料号是否重复
2.更新价格时，自动在价格历史表记录旧价格
3.批量修改时，先让大模型生成SELECT预览影响范围，再确认执行UPDATE
4.删除操作需二次确认，删除前检查是否被BOM引用，如有引用则提示
5.涉及JSON字段更新时，使用JSON_SET等函数
6.操作完成后记录到操作日志表

业务场景3：封装文件管理
用户需要上传、下载、查询PCB封装文件（.psm、.dra、.pad等），并在物料与封装之间建立关联。
自然语言需求示例：
"上传0805_L封装的psm文件，版本1.1，用于Allegro 17.4"
"帮我下载SOIC-8封装最新版本的dra文件"
"哪些物料用了BGA-256封装？列出物料内部料号和描述"
"给内部料号IC-STM32F103-001关联封装LQFP-48，设为首选封装"
"哪些封装还没有上传任何文件？"
"显示0805_L封装的所有历史版本文件"
"下载次数最多的是哪10个封装文件？"
预期系统行为：
1.上传时，大模型解析文件名、类型、版本等信息
2.上传新版本时，自动将旧版本标记为非当前
3.下载时，记录下载日志并更新下载计数
4.关联物料和封装时，检查是否已存在关联
5.查询缺失文件的封装时，用LEFT JOIN + IS NULL
